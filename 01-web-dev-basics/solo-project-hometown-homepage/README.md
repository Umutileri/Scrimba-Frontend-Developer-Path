# Hometown Homepage – Zonguldak

A simple homepage introducing **Zonguldak**, my hometown in Türkiye.

This project was created as part of the Scrimba Frontend Developer Path to practice HTML and CSS fundamentals.

## Features

- Hero section introducing Zonguldak
- Top activities and places to visit
- Historical places and landmarks
- A personal local guide section

## Built With

- HTML5
- CSS3
- Flexbox

## What I Practiced

- Structuring a webpage with HTML
- Styling elements with CSS
- Using Flexbox for layouts
- Working with background images
- Adding hover effects and transitions
- Using CSS variables
